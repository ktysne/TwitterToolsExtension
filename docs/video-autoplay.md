# 動画の自動再生の停止

## やりたいこと

タイムラインの動画が、スクロールで画面に入ると勝手に再生される。
これを止め、停止状態で表示する。
ただし、ユーザーがサムネイルをクリックしたときは通常どおり再生させる。

## X の再生のしくみ

X はタイムラインの動画を `<video autoplay>` 属性では再生していない。
JavaScript から `video.play()` を呼ぶことで再生している。
画面内に入ったかどうかを監視し、入った動画に対して `play()` を呼ぶ作りである。

調べた時点の動画要素は `autoplay` が `false`、`muted` が `true` で、再生位置だけが進んでいた。
これはミュートでの自動再生が JavaScript 経由で行われていることを示す。

## 抑止の方法

`interceptor.js` は MAIN world で `HTMLMediaElement.prototype.play` を上書きする。
呼ばれたときに「ユーザー操作に紐づく再生か」を判定し、紐づかない再生(自動再生)だけを弾く。

判定には `navigator.userActivation.isActive` を使う。
クリックやタップの直後はこれが `true` になる。
スクロールで入った動画に対する `play()` は、直前のユーザー操作が無ければ `false` になる。

弾くときは、対象を `pause()` してから解決済みの Promise を返す。
呼び出し側が `play().then(...)` のように使っていても壊れないようにするためである。

オン/オフは `data-tte-autoplay` 属性で切り替える。
属性が未設定のときは抑止しない(安全側に倒す)。

## 検証結果

実環境でこの上書きを入れ、動画検索をスクロールして確認した。

- スクロール中、X は自動再生を 92 回試みたが、すべて弾かれ、再生中の動画は 0 件だった。
- その後サムネイルをクリックすると、その動画だけが再生され、音声つきで再生位置が進んだ。
- ブロック回数は 92 のままで、クリックでの再生は弾かれていない。

自動再生だけを止め、手動再生を保てることを確認した。
